# Submission checklist — Oxford Bulletin of Economics and Statistics

Portal: Wiley Research Exchange / ScholarOne via https://onlinelibrary.wiley.com/journal/14680084 (Submit an Article).

## Files to upload
- [ ] `manuscript.docx` — main text, inline figures/tables, OMML equations, ~9,200 words incl. references (< 10,000 limit)
- [ ] `title_page.docx` — author details + Declarations (competing interests, data availability, generative-AI, ethics, funding)
- [ ] `cover_letter.docx` — first-person singular, journal-specific fit argument
- [ ] `supporting_information.docx` — SI (14 supplementary figures, 15 supplementary tables)
- [ ] `Figure_1.png` … `Figure_5.png` — separate figure files (Wiley asks for editable/separate art at submission)
- [ ] `figures_en.pptx` — editable figure source (optional convenience upload)
- [ ] `table*.docx` — editable table files

## Journal requirement notes
- Abstract present (≤ ~300 words); JEL codes E01, E22, O33, O47; keywords listed.
- Author–date (Harvard) references — current style compatible; Wiley will restyle post-acceptance.
- No submission fee; standard (non-OA) licence route = $0.
- Word count: ~9,200 incl. references — under the ~10,000 guideline.
- Declarations are on the title page; if the portal asks separately, reuse the title-page Declarations block verbatim.

## Local-only placeholders (fill at submission, no blocker)
- Portal account details and institutional affiliation confirmation.
- Suggested reviewers (if requested): see internal_qc/GATE2 notes — recommend checking current OBES editorial board for conflicts before naming; none fabricated.
- Any ORCID verification step in the portal (ORCID on title page: 0000-0001-7261-9062).
